## 사이트 이용과 외부 서비스

이 블로그는 VitePress로 만든 정적 사이트이며, 자체 회원가입이나 문의 입력 폼을 제공하지 않습니다. 사이트 안의 글 검색은 브라우저에서 처리합니다. 외부 검색 링크를 선택하면 해당 서비스로 이동합니다.

호스팅에는 Cloudflare Pages를 사용합니다. 페이지 제공과 보안 처리 과정에서 IP 주소, 요청 시각, 브라우저·기기 정보 등의 접속 정보가 Cloudflare에 전달될 수 있습니다. 실제 로그 수집 설정, 운영자의 열람 범위와 보관 기간은 [운영자가 Cloudflare 설정 확인 후 입력]합니다. 자세한 사항은 [Cloudflare 개인정보 안내](https://www.cloudflare.com/privacypolicy/)를 참고해 주세요.

글의 댓글은 Giscus와 GitHub Discussions를 이용합니다. 댓글 영역을 불러오면 Giscus에 접속 요청이 발생하며, 댓글을 작성하는 경우 GitHub 계정과 댓글 내용이 GitHub에서 처리되고 공개될 수 있습니다. 자세한 사항은 [Giscus 개인정보 안내](https://github.com/giscus/giscus/blob/main/PRIVACY-POLICY.md)와 [GitHub 개인정보 처리방침](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)을 확인해 주세요.

글꼴은 Google Fonts에서, 일부 소개 이미지의 아이콘은 Google 서비스에서 불러옵니다. 해당 요청에는 IP 주소와 브라우저 정보 등이 전달될 수 있습니다. [Google 개인정보 처리방침](https://policies.google.com/privacy?hl=ko)에서 처리 방식을 확인할 수 있습니다. 브라우저에는 화면 테마 등 사이트 이용 설정이 저장될 수 있습니다.

## 광고와 쿠키

이 블로그는 Google AdSense 도입을 준비하며, 사이트 소유권 확인을 위해 Google AdSense 스크립트를 불러옵니다. 이 과정에서 Google에 접속 요청이 전달될 수 있습니다. 광고 게재 여부는 Google의 심사 결과와 광고 설정에 따라 달라집니다. 광고와 쿠키에 관한 안내는 다음과 같습니다.

Google을 포함한 서드 파티 공급업체는 방문자가 이 사이트나 다른 웹사이트를 방문한 기록을 바탕으로 광고를 제공하기 위해 쿠키를 사용할 수 있습니다. Google 광고 쿠키를 통해 Google과 광고 파트너는 이 사이트 및 인터넷의 다른 사이트 방문 기록에 따른 광고를 제공할 수 있습니다.

서드 파티 광고 게재를 허용하면 다른 광고 공급업체와 광고 네트워크도 쿠키를 사용할 수 있습니다. 실제로 사용하는 광고 파트너 목록 및 각 개인정보·거부 설정 링크는 [운영자가 광고 활성화 전 실제 설정에 맞춰 입력]합니다.

방문자는 [Google 광고 설정](https://myadcenter.google.com/)에서 개인 맞춤 광고를 관리하거나 거부할 수 있습니다. 다른 참여 공급업체의 개인 맞춤 광고 쿠키 거부는 [AboutAds 선택 페이지](https://www.aboutads.info/choices/) 또는 해당 공급업체가 제공하는 설정에서 할 수 있습니다. Google의 데이터 사용 방식은 [Google 파트너 사이트 데이터 안내](https://policies.google.com/technologies/partner-sites?hl=ko)를 참고해 주세요.

브라우저 설정에서 쿠키를 삭제하거나 차단할 수도 있습니다. 쿠키 차단은 로그인 등 일부 외부 서비스 기능에 영향을 줄 수 있으며, 개인 맞춤 광고 거부가 모든 광고의 중단을 뜻하지는 않습니다. 동의가 필요한 지역에 광고를 제공하기 전에는 해당 지역 요건에 맞는 동의·철회 수단을 마련하고 이 안내를 갱신합니다.

## 문의와 변경 안내

개인정보 관련 열람·정정·삭제 요청은 [문의 페이지](/contact)의 이메일로 보내 주세요. 이메일 문의 시 발신 이메일 주소와 문의 내용이 네이버 메일을 통해 전달됩니다. 외부 서비스에 보관되는 댓글이나 계정 정보는 해당 서비스의 관리 기능과 정책도 적용됩니다. 서비스 구성이나 처리 방식이 바뀌면 이 페이지의 내용과 시행일을 함께 갱신합니다.
