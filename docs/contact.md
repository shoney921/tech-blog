# 문의

이 블로그는 Shoney가 개인적으로 운영합니다. 글의 오류, 출처·저작권 관련 요청, 사이트 이용 문제, 개인정보 관련 문의를 받기 위한 페이지입니다.

**문의 이메일: [ddmczp@naver.com](mailto:ddmczp@naver.com)**

문의는 위 이메일로 보내 주세요. 이 페이지에는 내용을 전송하는 문의 폼이 없습니다. 공개 프로필은 [GitHub shoney921](https://github.com/shoney921)에서 확인할 수 있습니다.

관련 글 주소, 문제가 있는 부분, 요청 사항을 함께 보내 주세요. 비밀번호, API 키, 주민등록번호 등 민감한 정보는 보내지 마세요. 개인정보 관련 요청은 공개 댓글에 남기지 말고 위 이메일을 이용해 주세요.

댓글은 공개될 수 있습니다. 댓글과 외부 서비스 이용에 관한 안내는 [개인정보 처리방침](/privacy)을 참고해 주세요.
