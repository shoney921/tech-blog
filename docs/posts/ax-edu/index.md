# AX 교육

사내 AX(AI Transformation) 교육 과정을 챕터 순서대로 정리한 노트. AI 모델 → 프롬프트 → 컨텍스트 엔지니어링 → 에이전트 → 품질·보안 → AIND → RX 순서다. Chapter 1이 맨 위다.

::: info 2026년 하반기 업데이트 · 2026-10-12 기준
각 챕터는 2026년 상반기에 쓴 원문을 그대로 두고, 그 뒤에 바뀐 모델·도구·가격·규제·실습 방법을 '2026년 하반기 업데이트' 박스로 덧붙였다. 박스 안에서 확인된 사실, 해석·전망, 확인하지 못한 것을 나눠 적었고, 출처는 각 글 맨 아래 '2026년 하반기 업데이트 참고자료'에 모아 두었다.
:::
