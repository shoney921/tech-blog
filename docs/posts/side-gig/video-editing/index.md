# 영상 편집 부업

Final Cut Pro를 이미 산 개발자가, 돈을 더 쓰지 않고 영상 편집 부업을 시작한다면 어떤 순서가 맞을까. 2026년 10월 12일 기준으로 공개된 자료와, 맥에서 직접 돌려 본 무료·로컬 테스트로 따져 봤다.

바쁘면 1편만 읽어도 된다. 결론과 실행 순서가 거기 있다.

1. **허브** — 결론, 수익 계산, 시작 순서
2. **편집기** — Premiere Pro와 Final Cut Pro. 이미 Final Cut이 있다면
3. **자막 서비스** — Vrew, CapCut, MacWhisper, 클라우드 API. 2026년 10월 기준 가격과 제약
4. **자막 직접 만들기** — 음성 전사, 자막 트랙 추출, OCR은 서로 다른 문제다
5. **따라 하기** — 42초 샘플로 전사 → 자막 정리 → FCPXML 러프컷
6. **Claude·Codex** — 편집 일에 붙이면 되는 것과 안 되는 것
7. **편집 앱 직접 개발** — 할 만한가. 작은 도구부터

::: tip 실측과 미검증을 나눠 쓴다
글에 나오는 숫자 중 **실측**이라고 적은 것은 맥(M4, 24GB, macOS 27.0.1)에서 합성 음성 샘플로 실제로 돌린 결과다. 사람 목소리, 실제 고객 영상, 유료 서비스, 유료 API는 테스트하지 않았다. 그쪽은 공식 문서와 커뮤니티 자료를 옮긴 것이고, 따라 할 수 있는 테스트 절차만 제안한다.
:::
