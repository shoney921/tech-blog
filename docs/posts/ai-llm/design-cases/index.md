# AI 아키텍처 설계 심화

[AI 시스템 설계 연재](/posts/ai-llm/ai-systems/)가 "LLM 호출 하나를 운영 가능하게 키우는 과정"이었다면, 이 세 편은 한 단계 위에서 묻는다. 같은 기술을 **케이스가 다르면 어떻게 다르게 설계해야 하는가.** 사내 문서 Q&A, 고객지원, 금융·법률처럼 인용이 엄격한 도메인, 백오피스 자동화, 기존 웹앱에 코파일럿 붙이기. 기술 세 편 뒤에 도메인 한 편을 붙였다. 각 편의 끝에는 서술형으로 설계안을 써야 할 때 쓸 수 있는 답안 뼈대를 뒀다.

1. 데이터 파이프라인과 근거(grounding) 데이터 설계
2. 에이전트 워크플로우와 LLM/RAG 아키텍처 설계
3. 에이전트 기반 동적 UI 연동 설계

2026년 10월 초 기준으로 확인한 버전과 수치를 썼다. 이 분야는 반년이면 표가 바뀌니 날짜를 같이 봐 주길.
